In This task I have creating a simple and interactive sales dashboard using a dataset Orders that included order date, region, product category, sales, and profit. The main goal was to visualize sales performance across different time periods, regions, and categories. To achieve this, I used Power BI to build three key visuals: a line chart showing sales trends over months, a bar chart comparing sales by region, and a donut chart representing sales by category and filled map chart for visualizing location and bar char for shipment mode and filter chart for segment. A slicer was also added to enable filtering by category for more detailed analysis. Colors were applied strategically to highlight the top-performing areas in terms of sales. After building the dashboard, I reviewed the visuals and wrote three short insights to summarize key trends and performance highlights observed in the data.
